# Component-Based Structure

## Shared Assets
- assets/css/platform.css
- assets/js/platform.js
- assets/js/viewer.js

## Shared Layout Blocks
- Topbar: logo, nav links, dark mode and language direction toggles
- Footer: all page links for no-dead-end navigation
- Breadcrumbs: local context and return path

## Functional Components
- Search form component (route to search page)
- PDF card component (open + download actions)
- Filter bar component (category/sort/search)
- Viewer toolbar component (page + zoom + print + download)
- Contact form component (client-side success feedback)

## Page Modules
- Home: hero + quick access + featured
- Library: filters + loading/empty/result cards
- Viewer: outline + embedded PDF + controls
- Categories: routing cards
- Search: dynamic result list with highlights
- Dashboard: saved/recent/account panels
- About: mission/features
- Contact: form/social channels
