# Wireframes

## 1) Home
- Sticky top nav
- Hero with CTA (View PDFs)
- Search input
- Quick access cards
- Featured documents grid
- Global footer links

## 2) PDF Library
- Breadcrumb: Home / Library
- Filter row: category, sort, search
- Loading state then card grid
- Empty state when no results

## 3) PDF Viewer
- Breadcrumb: Home / Library / Viewer
- Left outline sidebar
- Right viewer area with toolbar
- Back to library CTA

## 4) Categories
- Breadcrumb and section title
- Category card grid
- Each card routes to filtered library

## 5) Search Results
- Breadcrumb and dynamic heading
- Search box at top
- Highlighted match cards
- Empty state when query is empty/no results

## 6) Dashboard
- Breadcrumb and account summary
- Saved PDFs card
- Recently viewed card
- Quick action cards

## 7) About
- Mission and features in split layout
- Readable copy with clean spacing

## 8) Contact
- Simple form + social/contact sidebar
- Inline feedback after submit
