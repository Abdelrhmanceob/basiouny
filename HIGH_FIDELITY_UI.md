# High-Fidelity UI Specification

## Visual Direction
- Style: minimal, modern, professional
- Palette: neutral backgrounds, dark readable text, blue accent
- Depth: soft card shadows and subtle gradient atmosphere
- Motion: reveal transitions + hover lift micro-interactions

## Typography
- Primary: Manrope (EN)
- Arabic support: Cairo
- Headings: 700-800 weights
- Body: 400-500 weights

## Responsive Rules
- Desktop: multi-column card and viewer layouts
- Tablet: reduced columns and stacked controls
- Mobile: single-column content and collapsible nav menu

## Accessibility
- Sufficient contrast for text and controls
- Keyboard-friendly controls and clear focusable actions
- ARIA labels on viewer and key controls
- Breadcrumbs for orientation across pages

## States
- Loading: shimmer blocks in library
- Empty: dashed neutral container with user guidance
- Feedback: contact form success message

## Dark Mode
- Token-based theme switch with local storage persistence
